# Security Policy

**Please do not open public issues for security reports.**

- Use GitHub **“Report a vulnerability”** (Security advisories) on this repository to disclose privately.
- If you prefer email, contact: security@yourdomain.example (replace if you have a security mailbox).
- We aim to acknowledge within 48 hours and coordinate a fix and disclosure timeline.

## Scope & Versions
Pin all findings to tag **v1.0.0-audit-candidate** unless otherwise requested. Include commit hash and steps to reproduce when possible.
